# QSAR model registry

Govern the QSAR catalog: list, summarize, compare, recommend, register, and persist models.

## Procedure

1. Use `qsar_describe_backends` / `qsar_describe_catalog` for capability and inventory questions.
2. List and summarize models with `qsar_list_catalog_models` / `qsar_summarize_catalog_model`.
3. Recommend with `qsar_recommend_catalog_model`; register/persist with `qsar_register_model` / `qsar_persist_registered_model`.

## Expected Outputs

- catalog_summary
- registered_model
